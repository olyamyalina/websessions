# Практическая работа №1. Вариант 15

## Описание

В программе реализована модель слоя доступа к данным. Данные хранятся в
памяти в виде списков кортежей и удаляются после завершения программы.

Используются три сущности:

- `Account` - аккаунт;
- `Message` - сообщение;
- `Feedback` - результат обработки сообщения.

## Функции и настройки

Для `Account` реализованы функции `create_account`, `get_all_accounts`,
`get_account_by_uid` и `edit_account`.

Для `Message` реализованы функции `create_message`, `get_all_messages`,
`get_message_by_uid` и `edit_message`.

Для `Feedback` реализованы функции `create_feedback`, `get_all_feedbacks`,
`get_feedback_by_uid` и `edit_feedback`.

Функция `get_next_uid` создаёт новый идентификатор. Функция
`get_data_sample` соединяет `Account` и `Message`, выбирает аккаунты за
последние 8 минут и возвращает их IP-адреса и аргументы сообщений.

Для работы с моделью реализован интерактивный режим `repl`. В программе
обрабатываются ошибки ввода и обращения к несуществующим записям.

## Запуск и проверка

Требуется Python 3.10 или новее. Сборка проекта не требуется.

Запуск программы:

```bash
python src/TCP.py
```

Проверка синтаксиса:

```bash
python -m py_compile src/TCP.py
```

Автоматические тесты на первом этапе не реализованы.

## Пример использования

```text
Введите команду: create_account
Введите IP-адрес: 127.0.0.1
Создан аккаунт: (0, <timestamp>, '127.0.0.1')

Введите команду: create_message
Введите аргумент: ping
Введите UID аккаунта: 0
Введите статус выполнения: 1
Создано сообщение: (0, <timestamp>, 'ping', 0, 1)

Введите команду: get_data_sample
Результат выборки: [('127.0.0.1', 'ping')]

Введите команду: exit
Выход из программы.
```

Вместо `<timestamp>` программа выводит текущую временную метку.
